### SSPanel Info


It is a panel executor. It's basically a tool that lets you run and execute other scripts directly inside the game. You just put the code into the panel and run it from there.

 ### Console

* The console in the script shows you exactly what's happening in the background. It displays the output, print statements, and any errors from the scripts you execute. It’s basically a debug log that lets you track if the code is running correctly or if something went wrong.
